# BECE1064 Young Children's Literature — v16.8 Topic 3 Quiz Integration

This update retains the dedicated trilingual Topic 3 lesson page, **The Art of the Picture Book**, and adds the approved ten-question student-facing quiz.

## Topic 3 quiz
- Ten approved MCQs, each with English, Mandarin Chinese and pinyin line-by-line without language labels.
- Four options per question and the approved answer key: **1-A, 2-B, 3-A, 4-C, 5-D, 6-B, 7-C, 8-C, 9-A, 10-D**.
- Question 5 uses the approved revised Option C wording.
- Answer checking, score, per-question correct answers and explanations are displayed after submission.
- Quiz answers, score and attempt count are saved in the current browser using localStorage.

## Run locally
Open `index.html` in a modern browser. For service-worker/PWA behaviour, serve the folder from a local HTTP server or deploy it to a static host.
